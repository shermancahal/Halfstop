The library

How it works

Open files, not a walled garden

Every map is published in the format it was recorded in — GPX, KML or KMZ — alongside a GeoJSON conversion. Download it, open it in GaiaGPS, Garmin BaseCamp, CalTopo or QGIS. Nothing here is locked to this site.

Real basemaps and overlays

USGS topo quads, aerial imagery, OpenTopoMap and street maps, with hillshade, hydrography and label overlays you can stack and fade independently — the layer control works the way it does in a proper GPS app.

Drop your own files in

The map opens a GPX, KML, KMZ or GeoJSON file straight from your computer and shows distance, ascent and an elevation profile. Those files are parsed in your browser and never uploaded anywhere.

Publishing a map

Three steps, no build tooling required.

  1. Export from GaiaGPS. Open the track or folder, choose Export, and pick GPX (best for tracks and waypoints) or KML/KMZ (best when you want folder structure and styling preserved).
  2. Drop the file into data/maps/. Optionally add a sidecar <name>.meta.json next to it with a title, description, region and tags.
  3. Run npm run build and commit. That regenerates data/catalog.json — bounds, distance and elevation are measured from the file itself — and the site picks it up on deploy.

No metadata file? That is fine. The builder falls back to the map's own name, and derives a title from the filename. The sidecar just gives you better copy and filtering.

Where this is going

The library first, then the app.

  • Shipped A map-first siteThe map is the homepage. Switchable topo, imagery and street basemaps with stackable overlays, distance and elevation stats, and a shareable URL for any view — with this library a click away.
  • Shipped Folders for your waypointsImport waypoints out of any map into folders you name, move them between folders, colour them, hide them, and export a folder back out as GPX. Kept in your browser — never uploaded.
  • Shipped Client-side GPX / KML / KMZ parsingFiles are read and measured in the browser, so the viewer opens your own recordings without an upload step or a server round trip.
  • Next Mapbox layersDrop a Mapbox token into the config and the viewer switches to Mapbox GL with vector styles, 3D terrain and any custom layers built in Mapbox Studio. The engine abstraction for this is already in place.
  • Next Offline-capable field appA lightweight installable version with cached tiles and saved maps for use where there is no signal — the part of GaiaGPS that matters most on the road.
  • Later Route drawing and editingSketch a route in the browser, snap it to roads and trails, and export it back out as GPX for the device you actually navigate with.
